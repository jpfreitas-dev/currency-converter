# 💱 Conversor de Moedas

Aplicação web simples para converter valores de **USD**, **EUR** e **GBP** para **BRL**.

## Sobre o projeto

Este projeto foi desenvolvido com HTML, CSS e JavaScript puro.
O usuário informa um valor, escolhe a moeda e visualiza o resultado convertido em reais.

## Funcionalidades

- Conversão de Dólar (USD) para Real (BRL)
- Conversão de Euro (EUR) para Real (BRL)
- Conversão de Libra (GBP) para Real (BRL)
- Exibição da cotação usada e do valor final formatado

## 📂 Organização dos arquivos

```bash
currency-converter/
├── index.html
├── scripts.js
├── styles.css
└── img/
```

## Como executar

1. Abra o site
2. Informe o valor
3. Selecione a moeda
4. Clique em **Converter em reais**.

## Tecnologias

- HTML5
- CSS3
- JavaScript (ES6)
